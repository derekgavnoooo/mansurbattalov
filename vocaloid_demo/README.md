# «Нотка» — демо-ролик с нарисованным вокалоидом

`nota_demo.mp4` — 31 секунда, 1280×720, 24 fps, со звуком. Персонаж, анимация, голос
и музыка сгенерированы кодом из этой папки. Готовые картинки и сэмплы не используются.

## Что в ролике

1. На листе бумаги пишется заголовок, потом появляются синие карандашные построения
   (круг головы, оси, линия плеч) и линии рисунка, штрих за штрихом, под звук карандаша.
2. Рисунок раскрашивается акварелью/маркером.
3. Нотка поёт песенку на русском: шевелит губами по слогам, качает головой и хвостиками,
   моргает, у гарнитуры пульсирует подсветка, вылетают нотки, снизу идут караоке-субтитры.
4. В финале она жмурится «^^», а на листе появляется «спасибо, что послушали!».

## Почему выглядит «от руки»

- **Дрожь линий (line boil).** Каждый рисунок держится 2 кадра («анимация по двойкам», 12 рисунков/с)
  и каждый раз «перерисовывается»: линии чуть смещаются плавным полем искажений. У каждого штриха
  ещё есть свой сдвиг, небольшой поворот и случайный перелёт за конец.
- **Нажим.** Штрихи сужаются к концам, толщина плавает, в линии видно зерно бумаги.
  Иногда рядом идёт вторая, неуверенная проводка.
- **Раскраска мимо контура.** Заливка сдвинута относительно линий, края волнистые, по краю
  скапливается пигмент, как у акварели. Плотность неравномерная, местами просвечивает бумага.
- **Ручная штриховка теней** с неровным шагом и разной длиной штрихов.
- **Недотёртые синие построения** просвечивают поверх рисунка.
- **Асимметрия.** Правая половина лица не зеркальная копия левой.
- **Бумага:** тёплый оттенок, зерно, волокна, виньетка как у фото на телефон, пятна графита
  у ребра ладони, малярный скотч по углам.
- **Рукописный текст** шрифтом Caveat (OFL): каждая буква со своим наклоном, базовой линией и размером.

## Звук

- **Голос** сделан аддитивным формантным синтезом, как у ранних синтезаторов пения:
  гармоники основного тона проходят через огибающую формант гласных сопрано.
  Есть портаменто, вибрато на долгих нотах, придыхание, а также шумовые и звонкие согласные
  (с, ш, т, к, л, р, н, м…). Текст разбит на слоги, и по тем же данным двигаются губы.
- **Минус:** арпеджио, бас, пэд, драм-машина (бочка, малый, хэты), реверб через свёртку.
- **Шорох карандаша** синхронизирован с появлением каждого штриха.
- Музыкальная шкатулка на вступлении и «звёздочки» при раскраске.

## Сборка

```bash
pip install numpy pillow scipy
python3 make.py nota_demo.mp4      # нужен ffmpeg; ~5 минут на 4 ядрах
python3 render.py 14.2 frame.png   # отдельный кадр в момент t (сек)
```

Файлы:

- `song.py`: таймлайн, мелодия, слова, синтез голоса и музыки.
- `ink.py`: «ручной» рендер (бумага, штрихи, заливки, штриховка, текст).
- `character.py`: персонаж, описанный контрольными точками.
- `render.py`: позы, расписание рисования, композиция кадра.
- `make.py`: сборка видео.
