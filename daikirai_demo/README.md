# Daikirai demo — свой вокалоид под припев «ダイダイダイダイダイキライ»

30-секундный ролик на отрезок 0:43–1:13 трека **ダイダイダイダイダイキライ / 雨良 (Amala) feat. 初音ミク VS 重音テト**.
Картинка нарисована процедурно с нуля, звук берётся из оригинального клипа.

## Стиль

Собран из присланных референсов:

- из **Baumkuchen End Credits** (Amala): плоская заливка, толстый чёрный контур, большие круглые глаза,
  острые зубки, простые однотонные фоны;
- из **Daidaidai**: красно-сине-фиолетовая палитра, растровые точки (halftone), текстура ткани, глитч,
  хроматическая аберрация, игровой интерфейс «1P VS 2P» с полосками HP, пиксельные субтитры, зрачки-крестики, занавес.

Анимация «на двойках» (12 рисунков в секунду): линии слегка дрожат от рисунка к рисунку, как в ручной анимации.

## Персонаж

Рэй, своя героиня: короткое растрёпанное каре (белое, с красным цветом снизу), пиджак с синим кантом
и золотыми пуговицами, красный галстук, разные глаза (красный и синий — тема «VS»), заколка-крестик, клык и ахоге.
Руки двигаются через инверсную кинематику (задаётся точка кисти), кисти умеют жесты: ладонь, указательный палец, «peace», кулак.

## Синхронизация с музыкой

- Доли и темп (~130 BPM) найдены автоматически (librosa). Начало припева совпадает с вступлением бочки.
- Склейки сцен стоят на долях, на каждой склейке короткий глитч. Голова качается, а штампы «ダイ», «解», «凡ミス» влетают в долю.
- Губы двигаются по огибающей выделенного вокала (REPET-SIM). Гласные взяты из чтения строки:
  あ/い/う/え/お дают разную форму рта.
- Время строк снято по смене субтитров в оригинальном MV.
- Субтитры: японский оригинал, фуригана над кандзи и английский перевод (перевод свой, вольный).

## Сборка

```bash
pip install numpy pillow scipy librosa
python3 make.py "<оригинальный клип Daidaidai>.mp4" daikirai_demo.mp4   # ~6 минут на 4 ядрах
python3 scenes.py 4.6 frame.png      # отдельный кадр (секунды от начала отрезка)
```

Файлы:

- `lyrics.py`: тайминг строк, чтения, перевод, доли и огибающая вокала (`analysis.json`).
- `flat.py`: плоский рендер (заливки, дрожащий контур, halftone, текст с фуриганой, пост-эффекты).
- `chara.py`: персонаж, лицо и эмоции, руки и жесты.
- `scenes.py`: 16 сцен и монтаж.
- `make.py`: сборка видео.

Шрифты: DotGothic16, Dela Gothic One, Zen Maru Gothic (SIL Open Font License, см. `fonts/OFL-*.txt`),
урезаны до нужных символов.

Трек и персонажи оригинального клипа принадлежат их авторам. Ролик — фан-демо для личного использования.
