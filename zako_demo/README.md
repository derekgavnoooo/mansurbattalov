# Zako demo — Рэй в манере клипа «雑魚 / 亞北ネル»

30 секунд (2:20.0–2:50.4 трека, финальный припев). Звук из оригинального клипа, картинка нарисована процедурно.

**Стиль** скопирован по приёмам из присланного MV: одна ровная тёмно-сливовая линия, плоская пастельная заливка без теней,
румянец штрихами, длинные рукава вместо сложных кистей. Кадр разбит на три вертикальные панели, они загораются по строкам
и в доли. Анимации почти нет: позы сменяются как готовые иллюстрации.

**Как устроено:**

- `rei.py`: Рэй в простой манере (голова и эмоции, тело, рукава с кулачками, ноги);
- `poses.py`: каждая поза нарисована отдельно под свою строку, плюс 4 танцевальные позы в полный рост;
- `zscenes.py`: тайминг строк (снят с подписей в клипе), раскладка панелей, губы по огибающей вокала;
- `analysis.json`: доли (136 BPM) и огибающая вокала;
- `zmake.py`: сборка.

В танцевальной части (2:20–2:29) подписей нет, как и в оригинальном клипе.

```bash
python3 zmake.py "<клип 雑魚>.mp4" zako_demo.mp4
```

Используются `../daikirai_demo/flat.py` и шрифты оттуда (Zen Maru Gothic, OFL).
